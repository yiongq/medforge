# W2 报告 · 思考型小模型的后训练消融(Qwen3.5-4B)

一句话结论:**在 thinking-native 基座上,三种主流后训练配方没有一种带来增益;蒸馏 SFT 显著降智,
自采样 DPO 无害但也无益。** 全部数字、方法与原始答卷公开可核。

> **订正(2026-09-03 审查)**:本报告的成绩表建立在一个未被记录的测量缺陷上——协议 v2 的
> temperature=0 让思考型基座在 8192 token 内大面积陷入复读循环、从未写出 `</think>`,而规则层只看末 2000 字,
> 会从循环里刮出「答案:X」判硬分。四个配置的未收尾率(CMExam / CMB-val / MedXpertQA):
> base-v2 25.7 / 26.1 / 65.4%,sft-v2 0.3 / 0.0 / 1.7%,sft-r1-v2 17.5 / 22.5 / 44.9%,dpo-v2 33.1 / 37.5 / 74.5%——
> 并不在同一测量制度下比较,§4「v2 已解决截断」不成立。
> 按「收尾 ∧ 结论可抽出 ∧ 答对」的严格可用口径重算同一批题([reports/usability.md](usability.md);
> 注意该表里的 `base` 行是 v1 存档,以下 base 均指 base-v2):
> - **sft-r1-v2**:CMExam **62.2% vs 59.2%**(配对 McNemar p=0.011)。这是唯一在严格口径下显著为正的比较,
>   它衡量的是交付可靠性而非答题正确率——同一抽取器不设守卫时基座反而领先(66.8 vs 63.1,p=0.002),
>   反超来自守卫从基座剥掉 151 题(7.5pp)未收尾答卷、从 sft-r1 只剥掉 19 题(0.9pp);
>   CMB-val 48.2 vs 48.9(p=0.91)、MedXpertQA 11.2 vs 10.9(p=0.85)未检出差异(CMB-val 仅 70 对不一致,功效不足以排除数 pp 的效应)。
> - **sft-v2**:「抄旧教材降智」只在两张中文卷上仍成立(CMExam −10.7pp、CMB-val −11.1pp,p<0.001);
>   困难卷严格口径 12.1 vs 10.9(p=0.38)无差异——原 −11.5pp 是基座从复读段刮出的分(基座该卷未收尾 65.4%)。
> - **dpo-v2**:三卷严格口径均显著低于基座(55.0 / 42.1 / 8.9,p≤0.033),收尾率倒退 7.4 / 11.4 / 9.1pp;
>   不设守卫时三卷持平。「持平」是宽口径把「更容易陷入复读、更少写完」遮住了——它学到的不是答得更对。
> - §2 的机制推论失去支柱:「困难卷两代教材同伤(25.1 → 13.6)」在严格口径下两个 SFT 臂都不低于基座,
>   「抄外部笔记本身破坏原生深推理」目前没有证据支撑;§3 的 413 题翻转同受截断不对称影响。
> 判分链已加截断守卫并落盘 finish_reason(协议 v3),本表保留为 v2 存档,待 v3 重跑后一次改定。

## 1. 成绩(协议 v2,同一批固定种子抽样卷)

| 配方 | CMExam(n=2000) | CMB-val(n=280) | MedXpertQA(n=1000) |
|---|---|---|---|
| Qwen3.5-4B(原装基座) | **70.8** [68.7, 72.7] | **59.6** [53.8, 65.2] | **25.1** [22.5, 27.9] |
| + SFT · 2024 GPT-4o 蒸馏 CoT | 59.3 (−11.5) | 47.5 (−12.1) | 13.6 (−11.5) |
| + SFT · 2025 R1 蒸馏 CoT | 67.5 (−3.3) | 53.9 (−5.7) | 13.6 (−11.5) |
| + DPO · 自采样验证器驱动 | 70.7 (−0.1) | 56.1 (−3.5) | 24.4 (−0.7) |

方括号为 Wilson 95% 置信区间。DPO 三项差值均落在基座区间内,判定为**持平**;
两个 SFT 的主力卷与困难卷差值均远超区间,判定为**显著下降**。

## 2. 发现一:蒸馏 SFT 对思考型基座是降智,且伤害不只来自教材质量

换更强的老师(2024 GPT-4o → 2025 R1)能大幅止损,但**只在中文选择题上**:

- 主力卷 −11.5pp → −3.3pp(教材质量确实是变量)
- 困难卷 **13.6% 对 13.6%**——两代教材摔在同一个数字上(基座 25.1%)

若伤害仅源于教材质量,困难卷理应同步改善。它没有。合理解释是:**「模仿外部推理风格」这个动作本身
覆盖了基座的原生长链思考**,而困难卷恰恰最依赖长链思考。

旁证(逐题层面可见):同一道「属含气骨」的单选题,基座思考 7.9k 字答对;抄旧教材后只写 301 字,
且把单选答成 "ABC"。压缩后的答卷文件体积也印证——基座三卷答卷 26 MB,抄旧教材版仅 1.3 MB。

## 3. 发现二:DPO 不是「没起作用」,而是「作用相互抵消」

只看总分会误判为「无事发生」。逐题转移矩阵显示模型行为其实变动剧烈:

| 考卷 | 基座错 → DPO 对 | 基座对 → DPO 错 | 净 |
|---|---|---|---|
| CMExam | 206 | 207 | −1 |
| CMB-val | 18 | 28 | −10 |
| MedXpertQA | 78 | 85 | −7 |

CMExam 上有 **413/2000(20.7%)的题目答案发生了翻转**,而净收益为零——训练确实改变了模型,
但方向近乎随机。这排除了「LoRA 没生效」这类工程故障,把问题定位到**偏好信号的质量与规模**。

四个待验证的成因假设:

1. **数据规模不足**:约 1,000 对偏好数据、52 个优化步。业界迭代式 DPO 通常在 5K–10K 对量级
2. **单轮离线**:DPO 是离线算法,一轮后模型分布已偏移,原数据随即"过期";业界做法是多轮迭代
   (采样 → 训练 → 用新模型重新采样)
3. **域与题型错配**:训练题是**英文开放题**,主力评测是**中文选择题**——偏好对学到的可能是
   "英文开放作答的风格偏好",迁移到中文选择题时成了噪声
4. **基座接近饱和**:4B thinking-native 在这些卷上可能已逼近其容量天花板

## 4. 方法与可信度

- **去污染**:训练题池对全部评测集做字符 10-gram 查重,污染样本剔除;短题干(占 CMExam 12%)
  如实标注为"字面查重无能为力"。报告:`reports/decontamination.md`
- **验证器**:规则层抽取答案声明 + LLM 仲裁兜底;上岗前经 200 题校准,一致率 96.5%,
  分歧方向偏严(对训练数据是安全方向)。报告:`reports/verifier-calibration.md`
- **评测口径**:temperature 0;弃权计错但单独统计(DPO 1.6–3.2%,基座 1.5–2.5%)
  〔订正:弃权率是真数,但它不含「未收尾」——同一批答卷 `</think>` 后抽不出答案的比例是基座 27 / 28 / 69%、DPO 34 / 39 / 77%,
  低弃权率是从复读段刮分造成的假象〕;
  抽样卷可靠性自证——基座抽样 2000 题得 70.8%,全量 6810 题得 71.1%
  〔订正:这是跨协议比较(全量卷是 v1 2048,抽样卷是 v2 8192),严格口径下两者相差 41.9pp,不构成抽样代表性证据〕
- **协议版本化**:v1(max_tokens 2048)会截断思考型模型的推理,已弃用但存档;
  W2 全部对比在 v2(8192)下完成

## 5. 已知局限

单随机种子、单次训练,未做多种子重复;判卷的"人工校准"实为强模型代理标注 + 人工抽检;
CMB-val 仅 280 题,其 ±6pp 的区间宽度不足以支撑细粒度结论;GRPO(在线强化)与 9B 规模复跑尚未进行。

## 6. 下一步(按成本排序)

1. **错题归因**(零成本):把基座答错的题分成"知识缺失/推理走偏/格式失误",决定该补检索还是补训练
2. **测时投票**(近零成本):同题多次采样取多数答案,业界常规增益 2–5pp,不改模型
3. **迭代 DPO**:数据加到 5K+ 对,并做 2–3 轮"采样→训练→重采样";同时把训练题源换成中文选择题,
   消除域错配这个变量
4. **GRPO**:在线强化,信号强于离线 DPO,是 o1/R1 的正统路线
5. **9B 复跑**:业界中文医疗微调的主流尺寸,验证"容量是否是本次无增益的成因"
