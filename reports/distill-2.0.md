## 2. 教材

5173 条老师样本(3000 题 × 2,少数失败)→ 五道闸门 → **3817 条医疗样本,覆盖 2123 题(79.7%)**,混 15% 通用回放共 4490 条。
思考 token p50 272 / p99 3.7k;老师每题判对率 94.2~94.6%。闸门明细见 distill-dataset.md。
成本:DeepSeek V4-flash 约 4.5M 输出 token,按当日价约 ¥30。

一次翻车记在案:首版闸门要求思考段中文占比 ≥ 50%,把 4300 条全砍到剩 27 条——老师和基座一样用英文思考,这道闸门方向反了;
长度估算按中文 1.6 字符/token 也把英文思考高估两倍。改用 API 返回的 completion_tokens、语言闸门默认关后恢复。

蒸馏 2.0 的贪心 + 强制收尾臂:CMExam 78.7、CMB-val 69.3、MedXpertQA 23.8,三卷收尾 100%——这个模型贪心下也不复读,forcing 只是保险;采样臂略优于贪心。

## 5. 怎么读

- **域内卷显著涨、迁移卷同向**:CMB-val 只有 280 题,最小可检出差异约 7pp,+5.7 落在边缘;MedXpertQA 老师自己只有 47%、
  4B 错题里 64% 老师也错,可教空间本来就小,持平符合预期。
- **不是背题**:题源已剔除与三张卷题干+选项完全一致的重题(主力卷真重题 12 道);CMB-val 与 MedXpertQA 完全不在题源内。
  但 CMExam 用了官方 train split,该卷结论应读作「域内」而非「泛化」,主力泛化证据是 CMB-val。
- **成本轴是同样重要的结果**:同分或更高的前提下每题 token 降到 1/3,这直接接得上部署侧的吞吐曲线。
- **老师与判卷员同厂(DeepSeek)**:严格口径由规则层判定(声明率 ≥ 99%),LLM 兜底占比 <1%,该风险对本表可忽略。
