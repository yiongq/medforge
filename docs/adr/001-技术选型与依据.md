# ADR-001 技术选型与依据

日期:2026-08-13 · 状态:已定稿(与项目所有者讨论敲定)

选型原则:**客观最优,不为展示性妥协;有标准库先用库,不胜任再自写。**
自写的只有三块没有现成库的项目特有逻辑:数据管线、验证器、报告分析层。

## 核心决策

| 决策 | 选择 | 依据 | 放弃了什么 |
|---|---|---|---|
| 基座 | Qwen3.5-4B 迭代 / 9B 定稿 | 2026-08 核查:AA 智能指数 9B=32、4B=27,各档第一且断档领先(第二名≈16);Apache 2.0;原生视觉留 VQA 门 | GLM(≤10B 通用停在 2025-04 上一代)、DeepSeek(无自研 ≤10B,蒸馏版落后代差) |
| 训练框架 | ms-swift | Qwen 官方推荐、新模型 day-1 支持、Megatron 路径留放大空间、国内网络零障碍 | LLaMA-Factory(九成重叠,生态协同稍弱)、自研训练循环(个人项目头号坟场) |
| 微调 | LoRA 全层 r=64【暂定】 | LoRA Without Regret:全层+足秩+10x 学习率 ≈ 全参效果、2/3 算力;40K 样本远在容量内 | 全参(同效更贵)、QLoRA(有小幅质量损失,显存不缺时不用) |
| 对齐 | SFT → DPO → GRPO 三档 A/B | DPO 小规模稳/省(arXiv 2512.22631:GRPO 优势在更大规模才显现);GRPO 是业界前沿路线(HuatuoGPT-o1/百川 M2),作正式对照组让数据说话 | 只跑一种(预设结论,违背「对比最佳」原则) |
| 评测 | 自写薄执行器(eval/run.py)+ EvalScope 仅用于压测 | **二次修正(W1b)**:审查证实四套考卷均不在 EvalScope 内置列表、判分必须复用已校准的 verifier.py——框架只剩「发请求」的价值,却带来插件 API 版本耦合(参照 ms-swift train_type 教训)。150 行薄执行器全链路本机可测(假 OpenAI 服务端),判分口径结构性唯一 | EvalScope 深度集成(自写适配的成本不省、风险更高);其压测能力(perf)保留使用 |
| 验证器 | 规则抽取 + LLM 兜底,provider 无关 | 规则层免费覆盖大多数;兜底走 OpenAI 兼容接口,DeepSeek/智谱/Claude 用 200 题人工校准集的一致率+单价选 | 纯 LLM 判分(贵且引入判分模型偏差)、纯规则(开放题判不了) |
| 量化 | FP8 主线 + AWQ 对照 | FP8 W8A8 是 Ada/Hopper 在线服务标准(近无损、~1.6x 吞吐);4B 在 24G 上不缺显存,AWQ 只做对照曲线 | AWQ 主线(weight-only 在高并发下几乎不提速) |
| 部署 | vLLM + Prometheus/Grafana | 行业默认(PyTorch Foundation 项目);自带 /metrics 与官方 Grafana 面板 | SGLang(功能趋同,生态较小;共享前缀负载才有优势) |
| 前台 | Vite + React,回放/live 双模式 | 「同题三模型并排流式对比」现成工具做不了;回放模式无 GPU 常年在线,live 模式起卡实时 | Gradio(颜值天花板低)、Next.js(SSR/服务端此场景用不上,多一层概念) |
| 实验追踪 | SwanLab | 国内 wandb 事实标准,ms-swift 原生集成,免费云版 | wandb(国内网络不稳) |
| 算力 | AutoDL 4090 / 定稿 9B 用 A100-40G | 4B LoRA 单卡 24G 富余;9B LoRA 24G 偏紧,定稿轮直接上 40G(≈3.3 元/时) | 常驻 GPU(demo 用回放模式替代) |

## 关键口径(违反即作废级)

1. **评测先行**:任何训练开始前,base 模型的三套考卷底分必须先落盘
2. **去污染是硬步骤**:训练数据对全部评测集做字符 10-gram + embedding 双查重,污染样本剔除、存疑样本进报告;报告必须公布查重方法与数字
3. **验证器先校准后上岗**:200 题人工判分集上一致率 ≥95% 才可用于 DPO 数据构造;判分口径全项目唯一(DPO 构造与评测共用 verifier.py)
4. **弃权计错**:评测口径里验证器弃权(correct=null)计入分母按错算,弃权率单独公布——不给格式混乱的输出发免费分
5. **可复现**:每个报告数字可追溯到 config + git hash + seed;数据/权重不进 git,脚本可重建

## 已知风险

- Qwen3.5 小模型幻觉率偏高(AA-Omniscience ~80%):恰是对齐训练的靶子,MedHallu 子集纳入评测
- 医疗合规:发布形态=开源研究+评测报告,不做在线问诊服务;README 带非医疗建议声明
- 观察项:Qwen3.8-27B 权重若落地(承诺 2026-08-10 当周)可作教师模型,不改基座选型
